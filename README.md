# 🌐 Abhinav Kumawat - Personal Portfolio

A modern, fully responsive personal portfolio website showcasing my skills, projects, certifications, and resume. Built with HTML, CSS, and JavaScript, this portfolio reflects my journey as an MCA student specializing in Cloud Computing and Java Full Stack Development.

- 🎨 Modern and responsive design

- 💻 Skills with animated progress bars
- 📂 Project filtering by category
